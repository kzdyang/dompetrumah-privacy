Kebijakan Privasi — DompetRumah

Terakhir diperbarui: 5 November 2026 · Paket com.dompetrumah.app

Ringkasan

DompetRumah adalah aplikasi pencatat keuangan rumah tangga yang bekerja luring (offline-first). Data keuangan Anda disimpan di perangkat Anda sendiri. Kami tidak memiliki server, tidak membuat akun pengguna, dan tidak mengumpulkan data pribadi Anda.

Data yang disimpan

  • Catatan dompet, transaksi, target tabungan, tagihan, dan utang/piutang.
  • Preferensi aplikasi (tema, mata uang utama, pengaturan pengingat).
  • PIN (disimpan sebagai hash PBKDF2 + salt — bukan angka aslinya), foto profil, dan lampiran struk yang Anda pilih.

Semua data tersebut disimpan hanya di perangkat Anda menggunakan penyimpanan lokal aplikasi (LocalStorage/IndexedDB).

Data yang dikumpulkan atau dibagikan

Tidak ada. Aplikasi tidak mengirim data keuangan Anda ke mana pun, tidak memakai iklan, dan tidak memuat SDK analitik/pelacakan pihak ketiga.

Koneksi internet

Aplikasi hanya menghubungi internet ketika Anda menekan tombol "Tarik Online" pada menu kurs, untuk mengambil nilai tukar dari penyedia publik:

  • cdn.jsdelivr.net (paket @fawazahmed0/currency-api)
  • latest.currency-api.pages.dev (cermin cadangan)

Permintaan tersebut hanya berisi permintaan data kurs; tidak ada data transaksi Anda yang dikirim. Seperti semua permintaan internet, penyedia CDN dapat melihat alamat IP perangkat Anda sesuai kebijakan privasi masing-masing layanan. Bila Anda tidak menekan tombol sinkronisasi, aplikasi tidak melakukan koneksi apa pun (selain memuat font dekoratif dari Google Fonts bila tersedia).

Izin perangkat

  • Notifikasi: menampilkan pengingat harian dan jatuh tempo tagihan. Dapat dimatikan kapan saja.
  • Alarm & pengingat: agar pengingat harian muncul tepat waktu. Bila izin tidak diberikan, pengingat tetap berjalan dengan waktu yang mendekati.
  • Biometrik (opsional): membuka kunci aplikasi dengan sidik jari. Data biometrik diproses oleh sistem Android, tidak pernah diakses aplikasi.
  • Penyimpanan: hanya saat Anda mengekspor cadangan/laporan ke file.

Cadangan dan ekspor

File cadangan (JSON/Excel/CSV) dibuat oleh Anda dan disimpan di lokasi yang Anda pilih. Aplikasi tidak mengunggahnya ke cloud mana pun. Anda bertanggung jawab menjaga kerahasiaan file tersebut.

Keamanan

  • PIN aplikasi berfungsi sebagai pengunci tampilan dan disimpan sebagai hash.
  • Data lokal tidak dienkripsi; perangkat yang telah di-root atau tidak terkunci dapat mengaksesnya.
  • Kami menyarankan mengaktifkan kunci layar perangkat dan mengekspor cadangan secara berkala.

Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah 13 tahun dan tidak mengumpulkan data dari anak-anak.

Penghapusan data

Hapus data dengan: menu Akun → Reset / Hapus data, atau hapus data aplikasi dari pengaturan Android, atau hapus instalasi aplikasi. Karena data hanya ada di perangkat, penghapusan bersifat permanen.

Privacy Policy — English

DompetRumah is an offline-first household finance tracker. All financial data is stored locally on your device. We do not operate servers, do not create user accounts, and do not collect personal data.

  • Stored locally: wallets, transactions, goals, bills, debts, preferences, PIN hash, profile photo and receipt images you attach.
  • Collected/shared: none. No ads, no analytics or tracking SDKs.
  • Network: only when you tap "Tarik Online", the app requests exchange rates from cdn.jsdelivr.net / latest.currency-api.pages.dev. No transaction data is sent.
  • Permissions: notifications and alarms for reminders; optional biometric unlock; storage only when you export a file.
  • Backups: files are created and saved by you; nothing is uploaded.
  • Security: the PIN is hashed, but local data is not encrypted; a rooted/unlocked device can access it.
  • Children: not directed to children under 13.
  • Deletion: reset inside the app, clear app data in Android settings, or uninstall.
  • Contact: 7kzd.yang@gmail.com
